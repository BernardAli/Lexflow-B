LEXFLOW AI | WORKING PROTOTYPE v0.12.0 | 30 OCTOBER 2026
==========================================================

1. Open README.md for full instructions.

2. QUICKEST START: In this folder, run:
      docker compose up --build
   Then open http://localhost:8000

   No Docker? On Linux/macOS run ./start.sh; on Windows run .\start.ps1
   Requires Python 3.12 and Internet for initial dependency installation.

   Existing Python 3.12 environment, port 3000:
      .venv-demo/bin/python -m uvicorn lexflow.main:app --host 127.0.0.1 --port 3000
   Open http://127.0.0.1:3000. Restart an old server after updating the project.
   This application uses FastAPI/Uvicorn, not manage.py runserver.

3. DEMO LOGIN:
      Email:     admin@keller.demo
      Password:  LexFlowDemo2026!

4. WALKTHROUGH:
   Dashboard -> Start guided demo -> Land register conflict
   -> Review each required field -> Approve -> Export JSON/CSV.

   NEW STRUCTURED CASE WORKFLOW:
   Open a matter -> Case details -> Add people/companies, properties and tasks
   -> Review extracted fields -> Confirm case details -> Approve
   -> Export Structured case bundle (JSON).
   Analysts prepare records; reviewers/admins confirm, approve and export.
